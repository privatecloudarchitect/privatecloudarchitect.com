Setting up this scorecard: one-time steps
The definitions ship in the bundle. Six steps make them live. Until the steps are done, a blank cell means an unwired metric. After they are done, a blank cell has a meaning (step 5 lists the three).
1 · Import order Super metrics first, then the five list views (Views ▸ Manage ▸ Import), then the dashboard (Dashboards ▸ Manage ▸ Import). Each layer references the previous one by id. The order is load-bearing.
2 · Activate each SM A super metric imports as a definition only. Set each one’s Object Type from the name’s object slot (Host System · Virtual Machine · Cluster Compute Resource). Set its Unit from the name’s suffix (%, GB, USD/month, count). Overcommit ratios stay on Auto.
3 · Policy enablement In PCA - WTPC - Policy - prod-latency-critical-db, enable the 35 posture super metrics. Also enable the 4 Shared and the 4 Rightsizing metrics the embedded drill-down renders. Per-policy enablement is the scoping mechanism: members compute, everything else stays dark. Never enable them in the Default policy.
4 · Tag hygiene Membership is three vCenter tags (env=prod · workload=db · sla=sla-1) on the VMs. Their hosts and clusters are derived from where those VMs run, so run the reconciler on a cadence to keep the infrastructure tiers current. A group condition matches on category and value together. A near-miss tag yields a silently empty group, not an error.
5 · What stays blank After setup, a blank cell has exactly three legitimate reasons. First: the object is not a posture member, so it computes nothing by design. A blank row on an unpostured object is the scoping working. Second: the metric is not yet enabled in the posture policy, or hasn’t completed a collection cycle. Third: the cost engine hasn’t attributed a value to the object yet (the blank dollar). One display note: units don’t travel through import, so if a GB column renders in base units, set the column unit once.
6 · Provider scope The dashboard imports with vSphere World as its default provider. Re-scope it to PCA - WTPC - Group - prod-latency-critical-db (Clusters) so every widget auto-filters to posture members.
Checklist and membership rule: the Well-Tuned Private Cloud posture catalog, posture prod-latency-critical-db. The bundle’s supermetrics.yaml and view XMLs are the single source of truth for every definition.
