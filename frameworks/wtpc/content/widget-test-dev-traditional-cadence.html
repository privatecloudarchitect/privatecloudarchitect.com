The operating rhythm
A tuned best-effort estate is a weekly habit. The tier sets the response: a breach here opens a ticket for the weekly review, it does not page.
Rhythm What you do
Weekly The density review. Work the most under-packed cluster first: consolidate more workload onto it. Then run the reclaim actions the evidence view has ranked on the clearly oversized VMs. Clear any red in the two floor cells before anything else.
Monthly The true-up. Drive unpostured inventory toward zero. Confirm the policy still matches the catalog. Check the estate governance dashboard for any cluster where this posture shares hardware with a stricter one: there, the stricter resident governs, and a best-effort VM holding a reservation is a tagging question to resolve.
Severity follows the tier. Every breach at this posture opens a ticket for the weekly review. The same envelope on a production posture would page. The response changes with the tier. The targets never do.
